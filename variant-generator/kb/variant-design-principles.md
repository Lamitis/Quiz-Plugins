# 变体题设计原则（variant design principles）

> 这份文档是插件资产，也是审题标准：`prompts/generate_variant.txt` 里的规则来自这里，
> 两边冲突时以本文为准，并同步修改模板。

## 1. 变体题的定义

> 变体题 = **同一考点 + 不同陷阱**的题。

两个条件缺一不可：

- 只同考点、陷阱照抄 → 换皮题（学生做过一遍还会做第二遍，练不到东西）。
- 只换情境、考点漂移 → 新题（不叫「举一反三」，叫「又出了一道题」）。

判断口诀：**能把原题和变体用一句话同时概括出来**，才算同考点。

## 2. 考点不变的三条硬线

| 硬线 | 含义 | 反例 |
| --- | --- | --- |
| 知识内核相同 | 同一个概念 / 机制 / 公式 / 鉴别点 / 操作原则 | 原题考「机制」，变体考「治疗首选」 |
| 判断依据相同 | 解题靠的那条规则还是同一条 | 原题靠「时间窗」，变体靠「剂量上限」 |
| 作答单位相同 | 单选仍是单选，答案仍是字母 / 文本 | 把单选改成了填空，考生要重学作答方式 |

## 3. 陷阱类型词典

| 编号 | 名称 | 做法 | 适合 | 风险 |
| --- | --- | --- | --- | --- |
| T1 | 同义替换 | 关键词换成教材同义词 / 英文缩写（「中性粒细胞」→「neutrophil」） | 概念记忆题 | 换得太生僻会变成考单词 |
| T2 | 逆向设问 | 「最可能」→「最不可能 / 不属于 / 除外」 | 鉴别、禁忌类考点 | 变体多到只剩套路，间隔使用 |
| T3 | 时间与病程 | 急性↔慢性、早期↔晚期、即刻↔数日后 | 病理、内科病程题 | 时间点写不清会变成争议题 |
| T4 | 数值边界 | 6 h→6 周、正常上限↔下限、成人↔儿童 | 参考值、药代 | 必须保证新数值仍落在确定的医学结论内 |
| T5 | 鉴别并列 | 干扰项放同章节易混疾病 / 同类药物 | 鉴别诊断 | 干扰项要真的「像」，不能是明显错的 |
| T6 | 限定词 | 加「首选 / 最 / 主要 / 直接 / 根本」 | 任何多因素考点 | 限定词不唯一 → 答案不唯一 |
| T7 | 多选组合 | 正确项与「对了一半、过了头」的项混排 | 多选 | 容易变成考语文 |
| T8 | 反向表述 | 把因果倒过来陈述（「因 X 而 Y」→「Y 导致 X」） | 机制、病理生理 | 表述绕，但要保证读两遍能读懂 |

## 4. 难度校准

| 目标 | 做法 | 不要做 |
| --- | --- | --- |
| `same` | 换个情境，考同一条规则 | 加参数、加计算 |
| `harder` | 把「直接识别」改成「两步推理」（先分型、再选处理） | 靠超纲章节制造难度 |
| `exam` | 换成真题口吻：加患者年龄、主诉、化验值 | 编造真实病例与指南推荐 |

**难度上升必须体现在推理步数上，不是体现在生僻程度上。**
超纲知识带来的「难」，考场上换不来分。

## 5. 常见失败模式

| 症状 | 病因 | 处方 |
| --- | --- | --- |
| 换个数字就交差 | 没有换陷阱 | 强制声明陷阱编号，且 ≠ 原题 |
| 变体比原题简单 | 干扰项写得太假 | 每个错误选项写清「对应哪种误解」 |
| 变体与原题考点不同 | 出题前没写「一句话考点」 | 先写考点，再动笔 |
| 答案不唯一 | 限定词缺失 / 干扰项也说得通 | 加「最 / 首选」，删「部分正确」的项 |
| 答案泄露 | 选项措辞暗示、解析语气提前暴露 | 答案整段进 `<!--ANSWER_START-->` 块 |
| 题干依赖原题 | 省掉了关键条件 | 自检「脱离原题能不能读懂」 |

## 6. 验收清单

- [ ] 一句话能同时概括原题与变体的考点
- [ ] 陷阱编号已声明，且与原题不同
- [ ] 每个错误选项对应一种具体误解
- [ ] 答案唯一、无争议、无「以上都对」
- [ ] 无超纲内容，无编造的指南推荐 / 剂量 / 分期
- [ ] 答案段完全落在 `<!--ANSWER_START-->` … `<!--ANSWER_END-->` 内
- [ ] 多题生成时，陷阱类型互不重复
