# 举一反三 · 变体题

下面这道题是学生刚做完的，请出一道**考点相同、陷阱不同**的变体题。

## 原题

- 题干：
{{QUESTION_TEXT}}
- 选项：
{{QUESTION_OPTIONS}}
- 正确答案：{{CORRECT_ANSWER}}
- 知识点：{{KNOWLEDGE_POINT}}
- 原题解析：{{ANALYSIS}}

## 一、什么叫「考点相同」

**必须保留**（动了就不是变体）：

- 知识内核：同一个概念 / 机制 / 公式 / 鉴别点 / 操作原则；
- 判断依据：解题靠的那一条规则，变体里必须仍然是同一条；
- 题型与作答单位：单选还是单选，答案仍是字母或文本。

**可以替换**（这是换陷阱的空间）：

- 情境：换患者、换器官、换药物、换实验条件；
- 数值：换剂量、时间、浓度、年龄（但不得改变正确选项）；
- 设问方向：「最可能」→「最不可能 / 首选 / 除外」；
- 干扰项：换成同一知识树上「长得很像」的错误选项；
- 信息呈现：文字 → 简表 / 化验单 / 流程描述。

**绝对禁止**：换考点；靠超纲知识制造难度；直接复用原题选项措辞；让答案不唯一或存在争议
（「以上都对 / 都不对」这类模糊结构一律不用）。

## 二、陷阱类型库（必须声明用了哪一种，且不能与原题同一招）

| 编号 | 陷阱 | 做法 |
| --- | --- | --- |
| T1 | 同义替换 | 题干关键词换成教材同义词 / 英文缩写 |
| T2 | 逆向设问 | 问「不属于 / 最不可能 / 除外」 |
| T3 | 时间与病程 | 急性↔慢性、早期↔晚期 |
| T4 | 数值边界 | 6 h 换成 6 周、正常上限换成下限 |
| T5 | 鉴别并列 | 干扰项放同章节易混疾病 / 药物 |
| T6 | 限定词 | 加「首选 / 最 / 主要 / 直接」 |
| T7 | 组合陷阱 | 正确项与「对了一半、过了头」的项混排 |
| T8 | 反向表述 | 把因果关系倒过来陈述 |

## 三、输出格式（严格照此；两个 HTML 注释标记必须原样出现，宿主按它们切分）

<!--VARIANT_META {"kp":"<知识点>","trap":"T1","difficulty":"same","base_type":"single_choice"}-->

## 变体题 · <知识点>

### 题干
<题干文本；原题带图时写「（原题此处有一张图，本变体不依赖该图）」>

### 选项

- D. …

### 作答

- **为什么**：<2–3 句，讲清判断依据>
- **陷阱**：T<n> <陷阱名> —— <一句话说明它怎么坑人>
- **与原题的关系**：同考 <知识点>；<原题错法> 说明 <漏掉的判断依据>

## 四、硬性约束

1. `<!--VARIANT_META …-->` 必须是第一行，JSON 单行合法，键固定为 `kp` / `trap` / `difficulty` /
   `base_type`；`difficulty` 固定 `same`，`base_type` 按原题推断（`single_choice` / `multi_choice` /
   `true_false` / `fill_blank` / `ming_jie` / `jian_da` / `jie_da`）。
2. `<!--ANSWER_START-->` 之前**任何文字**都不得泄露答案，包括「显然」「正确答案」「排除一下」这类暗示。
3. 只出一道题；陷阱编号必须与原题不同（看不出原题用哪种时，任选一种并在解析里说明）。
4. 题干自足：脱离原题也能读懂；选项互斥、答案唯一；每个错误选项对应一种具体误解。
5. 解析不超过 6 行，不复述原题解析；不编造指南推荐、剂量、分期标准、参考值。
6. 不写「以下是为你生成的变体题」「希望这道题对你有帮助」这类元话语。
7. 信息不全时：缺正确答案 → 第一行标 `⚠️ 信息不全：缺正确答案`，并说明变体基于什么假设；
   缺知识点 → 从题干推断，并在 META 的 `kp` 后加「（推断）」；题干残缺到读不出考点 →
   只回一行 `⚠️ 信息不足：请补充题干 + 选项 + 正确答案`，不要硬出题。

现在直接输出，不要解释你在做什么。
