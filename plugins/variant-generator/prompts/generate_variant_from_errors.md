## 一、先选题，再出题

1. 看每道题的「错了几次」，把错得最多的那道当原题（并列时取靠前的）。
2. 其余错题只用来挑干扰项（同一知识树上长得像的错误项），**不要**一题多问。
3. 原题怎么坑人的，变体不许用同一招：换一种「错的方式」，并写出编号与坑点。

陷阱类型库：T1 同义替换 · T2 逆向设问（不属于 / 最不可能 / 除外）· T3 时间与病程（急性↔慢性）·
T4 数值边界（6 h 换成 6 周）· T5 鉴别并列（干扰项放易混病 / 药）· T6 限定词（首选 / 最 / 主要）·
T7 组合陷阱（正确项与「对了一半」的项混排）· T8 反向表述（把因果倒过来）。

## 二、必须保留 / 可以替换

- **必须保留**：知识内核（同一概念 / 机制 / 公式 / 鉴别点 / 操作原则）、判断依据（解题靠的那条规则）、题型。
- **可以替换**：情境（换患者 / 器官 / 药物）、数值（不改正确选项）、设问方向、干扰项、信息呈现方式。
- **绝对禁止**：换考点；靠超纲知识制造难度；复用原题选项措辞；答案不唯一或用「以上都对」。

## 四、硬性约束

1. `<!--VARIANT_META …-->` 必须是第一行，JSON 单行合法；`difficulty` 固定 `same`，
   `base_type` 按原题推断。
2. `<!--ANSWER_START-->` 之前**任何文字**都不得泄露答案，包括「显然」「正确答案」「排除一下」。
3. 只出一道题；题干自足、选项互斥、答案唯一；每个错误选项对应一种具体误解。
4. 解析不超过 6 行；不编造指南推荐、剂量、分期标准、参考值。
5. 不写「以下是为你生成的变体题」「希望这道题对你有帮助」。
6. 错题材料为空时，只回一行 `⚠️ 信息不足：请补充题干 + 选项 + 正确答案`，不要硬出题。
