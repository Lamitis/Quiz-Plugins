# 小抄写作规范（cheat-sheet style guide）

> 这份文档是**写给人和 AI 一起看的规则书**：它既是插件资产（可被宿主的
> `kb.read` / `kb.search` 检索），也是审稿时的验收标准。改规则请改这里，
> 不要只改 prompt——两份东西不一致时以本文为准。

## 1. 什么算「小抄」

小抄 = **考前最后 5 分钟要过的东西**。判断标准只有一条：

> 用户在考场门口站着看，能不能在 5 分钟内看完并记住大部分？

不能，就不是小抄，是复习资料。复习资料有别的入口，不用挤在这一页里。

## 2. 密度与取舍

| 内容 | 收 | 不收 |
| --- | --- | --- |
| 结论 | 「急性炎症早期以中性粒细胞为主」 | 「炎症是机体对损伤因子的防御反应……」 |
| 数字 | 「PaO₂ 80–100 mmHg」「t₁/₂ ≈ 4 h」 | 「氧分压正常」（没有数字等于没说） |
| 公式 | 写全公式 + 单位 + 适用条件 | 只写符号名，不给式子的条件 |
| 对比 | 一行一个维度、3–6 行 | 把整章鉴别诊断表搬过来 |
| 口诀 | 通行口诀 + 展开说明 | 生造的、展开不了的顺口溜 |
| 错因 | 「把 X 记成 Y，因为 Z 长得像」 | 「粗心」「没复习」这类没有信息量的归因 |

砍的优先级（从先砍到后砍）：**口诀 → 鉴别对照 → 必背条目 → 避坑指南**。
避坑指南是唯一不可替代的部分：它来自用户真实错过的题。

## 3. 医学表述的边界（重要）

1. **不写绝对化结论**：能写「多数」「首选」「一线」就不要写「一定」「必须」，
   除非指南确实是这么规定的。
2. **剂量、单位、参考值必须带出处口径**（教材范围 / 指南年份）；拿不准就标 `（待核）`，
   或直接不写。写错一个参考值比不写有害得多。
3. **口诀只是记忆钩子，不是知识本身**：每个口诀后面必须列出它覆盖的知识点，
   否则用户只会背顺口溜不会用。
4. **不做临床决策建议**：小抄服务于考试。涉及用药/抢救流程时只写考点口径，
   不写「遇到 X 就怎么处理患者」。
5. **中文 + 英文原词**：COX-1、pKa、Frank–Starling 机制这类不要硬译，
   考试题干常常直接用英文缩写。

## 4. 常见失败模式

| 症状 | 病因 | 处方 |
| --- | --- | --- |
| 整页都是定义 | 把「解释」当「干货」 | 每条删到只剩结论 + 条件 |
| 抄了题目解析 | 直接复制 `analysis` 字段 | 先聚类同考点，再写一条共同结论 |
| 数字满天飞但记不住 | 没有取舍 | 一个知识点最多 2 个数字 |
| 口诀对不上题 | 口诀没有展开 | 口诀后强制写「展开：A / B / C」 |
| 覆盖了 20 个知识点 | 舍不得砍 | 按错题数取前 5–7 个知识点 |
| 通篇「⚠️」 | 避坑写成了吐槽 | 每条避坑必须有「正解」 |

## 5. 审稿清单（人审也用这份）

- [ ] 5 分钟能看完（A4 单页、≤ 60 行）
- [ ] 每个条目都来自这批错题或知识库，没有「通用常识凑数」
- [ ] 没有资料里不存在的数据、口诀、公式
- [ ] 避坑条目都能对应到具体错题
- [ ] 打印出来黑白可读（不依赖颜色区分）
- [ ] 没有题库名、题号、分数、「作为 AI」这类元话语
